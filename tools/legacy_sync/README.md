# 旧版本地同步

采集器只连接旧 MySQL；素材工具只读取旧对象源并写入新版 `abeiai` R2；导入器只连接本地 `127.0.0.1:3604/abei`。三种运行环境分别提供配置，禁止把旧 MySQL 和目标 PostgreSQL 凭据放进同一进程。

源端只有固定 SELECT、信息架构查询、只读会话设置和事务回滚。账号本身仍可能有写权限。断连、架构变化或数量不一致使整包失效；数据库快照不能断点续采。源业务 API、旧 Django 应用、Redis、源对象写入和云访问策略修改不参与同步。

## 包与素材

安装 `requirements.txt` 的固定依赖，使用 Python 3.12。密钥是独立的 32 字节文件，存放在包目录外，权限 `0600`。包是 AES-256-GCM 加密的 gzip NDJSON，保留字符串形式的整数、金额、原始 JSON，以及上海本地时间和对应 UTC。密码哈希及疑似凭据字段使用受限分片。验证完整 176 表结构、主键覆盖、分片数量和哈希后，才允许素材扫描和导入。

素材索引的 URL、归属、引用和结果负载加密；本地 `0600` SQLite 保留表名、源主键、顺序、状态和内容摘要等运行元数据。索引绑定包身份，表清单和完成结果经过认证，缺失或篡改不能被视为完成。原对象没有版本标识时，记录 `download-time-only`，不声称素材与数据库同一时刻一致。

目标对象位于 `picture-books/legacy-sync/abeiai-v1/<sha256>.<扩展名>`，直接使用现有公开域名。上传采用条件创建，校验长度和摘要，不覆盖已有对象。媒体临时缓存随文件复制完成清理。索引可断点续传；过期、缺失、未获准来源或无法识别的格式保留 MISSING 明细。原始财务记录、用户密码和配置不会上传到 R2。

## 原生导入

| 旧实体 | 本地对应 | 规则 |
| --- | --- | --- |
| 用户 | User | 保留状态、时间和受支持密码哈希；旧 staff 不成为管理员；身份冲突隔离，不自动合并 |
| 对话、图片、语音、视频及多轮语音 | LegacyAiLog / Session / Item / Asset | 全状态导入，保留孤立记录；会话归属检查；素材指向新 R2 |
| 兼容的绘本作品 | PictureBook | 有明确用户及中文页面结构才映射；不恢复已删除作品；不伪造生成任务或扣费 |
| 已复制素材 | MediaAsset | 保留可信归属；同一原件可被多个记录引用；历史迁移原件不参与头像和课程封面物理清理 |
| 其他业务实体 | 加密原始档案 | 不冒充当前任务、支付结算、可用点数或已生效会员权益 |

没有真实邮箱的用户使用内部地址，前台显示“未绑定邮箱”，禁止邮件投递和邮箱找回。旧公众号 AppID 的 SHA 描述必须与实际 `WECHAT_APP_ID` 相符，才启用 MP OpenID 和 UnionID。小程序身份不会被误当成公众号身份。

Django `pbkdf2_sha256` 哈希可验证，迭代次数不超过 200 万。用户成功证明密码后以原哈希、账号状态和密码能力做 CAS 升级；重复导入不会覆盖升级后的密码。手机号不自动标记已验证。

导入是增量插入，源命名空间和主键生成稳定 ID。`--dry-run` 只读目标库并生成加密预检报告。`--phase records --allow-pending-assets` 可先落地用户和日志，但素材仍标记待迁移；后续 `--phase assets` 更新已复制素材。只有所有对象尝试完成并对账后，才能汇报最终结果。资产更新不覆盖用户已编辑的绘本或已有头像。

## 后续开发要求

1. 订单档案：覆盖旧会员、作品、模板及开放平台订单，保留原金额、货币、支付标识和状态；审定订单类型与状态映射，禁止重放支付回调和履约。
2. 点数与权益：确认旧点数单位、余额组成、会员到期、赠送及历史流水的转换规则和截止时刻，再开发余额/权益导入；当前没有激活旧余额。
3. 通用旧作品档案：补充模板结果、批次、多作品结果、修订历史、作品分组、公开/私密状态及源字段路径；现有 PictureBook 不能完整表达这些结构。
4. 内容兼容：旧 CMS 的 HTML、模板、重定向和案例关联需要渲染与路由适配；旧多语种页面、诗词标签、文档/工作区、分享和开放平台归属需各自定义映射。
5. 排除的认证会话、API 密钥和权限表不会成为新系统登录凭据。开放平台密钥的非敏感归属如需继续运营，应另做只读补充清单，重新签发密钥。
6. 缺失素材按加密索引逐条补档；AAC/M4A 识别和 Ogg 视频后台预览兼容是已记录的后续项。

验收入口：`http://localhost:3600/admin/users`、`http://localhost:3600/admin/ai-logs?source=LEGACY`、原用户绘本页面。历史日志正文及代理文件接口仍需管理员身份。
