# 绘本导读

入口：`/picture-book-guide`，工具箱中显示“绘本导读”。桌面采用历史记录、逐页阅读和带读设置三栏，手机按相同顺序堆叠。

## 使用流程

1. 登录并选择主账号，上传 PDF。限制为 50MB、1–80 页，保留封面、插画页和空白页的原始页号。
2. 选择适用对象：婴儿期0-1岁、幼儿期1-3岁、幼儿园、一二年级、三四年级、五六年级、初中、高中及以上，与绘本创作一致。
3. 选择戏剧表演型、交互启发型、分级导读与语言精读型、探究思辨型或温柔陪伴型。点击信息图标查看当前风格说明。
4. 先生成全部页的文稿，可逐页编辑、保存和重新生成。中断后可继续尚未完成的页面。
5. 全部文稿完成后，选择音色和语速，生成逐页语音。每页可单独播放、下载和重新生成；勾选连续带读后，当前页播放完成会翻到下一张已有语音的页面。

修改文稿会清除该页当前语音；修改适用对象或风格需要确认，随后清除全部当前文稿和语音。旧的成功语音任务仍保存自己的固定产物地址，直到这份导读被删除。音色默认选择音色库的有效默认项，缺少可用音色时不能生成语音。

## 模型和存储

- 文稿使用现有 AiService 的视觉生成、计费和流式输出。首次生成时注册 `picture-book-guide` 场景，默认绑定 `vision` 别名；管理员可为该场景指定专用别名。需要启用且支持 TEXT / VISION 的模型。
- 语音复用现有 AudioService，按所选音色寻找适配的 TTS 模型，继续使用现有点数预占和结算。
- PDF、页面预览和语音保存在私有目录，所有文件接口验证账号所有者。语音直接私有落盘成功后才结算，任务响应不保存供应商公开地址或音频 Base64。
- Compose 新增 `abei_picture_book_guides` volume，仅挂载 API 容器，不挂载 Nginx。默认容器目录是 `/app/private-picture-book-guides`，可通过 `PICTURE_BOOK_GUIDE_STORAGE_DIR` 指定绝对路径。
- 本地开发必须使用 abei 的 PostgreSQL 3604 和 Redis 3605，不使用上游 xueleai 实例。
- 并发生成通过数据库租约及版本校验串行处理；失败解锁，过期任务不能覆盖后来保存的设置或文稿。已完成但未关联页面的语音任务可以恢复，避免重复调用和扣点。

## 数据库和本地更新

新增 `PictureBookGuide` 表及 User 关系，迁移为 `20261008090000_picture_book_guides`，不修改原表数据，不需要 seed 更新。

```bash
pnpm db:generate
pnpm --filter @xueleai/database build
# DATABASE_URL 必须显式指向本地 abei 数据库，再执行：
pnpm db:migrate:deploy
docker compose build api-core web
docker compose up -d --no-deps api-core web
```

发布同步不能包含 `private-picture-book-guides`，应单独备份和保留对应私有数据卷。
