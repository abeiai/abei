# 推荐码与个人主页实施计划

目标：所有账号拥有唯一的 8 位随机小写字母数字组合主页地址；支持至少 4 位小写字母的固定名称申请；首次访问归因 72 小时，新账号注册成功后双方各获得 500 点。

范围：apps/web、apps/api-core、packages/database 及本文档。保留当前未提交的字典、打字、带学等改动；不修改支付定价、AI 功能、生产环境。

设计：推荐地址共用唯一命名空间，随机码永久有效。自定义名称由用户自行绑定且仅有一次机会，禁止包含 xuele、官方保留名称，绑定后永久不可修改。公开页只返回公开资料，私有账号信息继续要求主账号身份。使用服务端生成、数据库保存哈希的随机归因凭据，首次有效归因不覆盖或延期，注册时以数据库到期时间为准。邀请关系、双向钱包增量及流水在同一个数据库事务中完成，每个被邀请账号仅能入账一次；未验证的测试手机验证码不具备奖励资格。

需要 migration：是，新增推荐地址、归因凭据、邀请奖励记录，并为老账号补齐随机地址；新账号通过数据库触发器自动生成。需要 seed 更新：否，不新增演示数据。
