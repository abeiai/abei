# 旧版数据同步到本地新版

> **For agentic workers:** 使用 superpowers:executing-plans 在当前会话执行；真实导出及本地导入前完成相应独立审查。步骤以勾选项记录。

**Goal:** 将旧版用户、可映射内容和四类日志同步到本地 abei，所有可读取图片、语音和视频上传用户指定的已有私有 R2 桶。

**Architecture:** 独立 MySQL 读取器生成加密一致快照；离线素材读取/上传器仅连接旧对象源和新私有 R2；离线导入器仅连接本地 abei PostgreSQL。来源主键映射和对象哈希保证重复运行不重复创建。没有语义兼容结构的数据保留在受限本地档案，并列后续开发要求。

**Tech Stack:** Python/PyMySQL/cryptography/boto3，TypeScript/Prisma，NestJS。

**Spec:** [旧版导出方案](../../legacy-data-export-plan.md)。用户在 2026-10-08 明确要求执行本地同步并上传 R2；确认 `dev.env` 覆盖库为来源，并回复“是的，继续”；选择已有私有 R2 桶，具体桶名与配置路径待补充。

## 全局约束

- 允许修改 `tools/legacy_sync`、迁移所需 `packages/database`、已有用户密码兼容及媒体/历史日志读取、必要测试、配置示例和本计划；旧源码及源环境文件只读。
- 来源库虽有可写权限且既有入口无 TLS，用户已确认继续；仍强制固定 SELECT、同连接 REPEATABLE READ/READ ONLY 快照、禁止业务 API/Redis/任何源端 DML/DDL。此例外记录在受限 manifest，不能称为只读账号。
- 源端和目标端凭据不进入同一个运行进程；包、身份映射、原始 URL/哈希与财务档案加密，密钥在包目录之外，公开日志仅记录数量、阶段和错误类别。
- 只连接本地 abei 3604；测试使用临时 abei 3606/3607，绝不使用 xueleai 资源。原有本地用户、任务、钱包和内容保留；不执行 reset、seed 或删除。
- 全量业务记录不按成功/活跃过滤；排除认证会话、API 密钥、执行配置。没有对应结构的作品/订单/权益等列开发要求，不冒充当前任务、支付结算或可用余额。
- 所有素材实体写入指定私有 R2 桶；保留字段路径、顺序及归属，禁止公开私密对象、回源上传、覆盖现有对象、修改云访问权限或触发生成。失效/不可读取素材有明细，不能宣称全部成功。
- 需要用于 R2 的媒体字段 migration；不把真实业务资料写入 seed。

## 审查重点

- 可写来源凭据也不能使采集器执行业务写 SQL；连接中断整包无效，不能跨快照续导。
- 时间、整数、金额、原始 JSON 精度无损；包被篡改、目录穿越和不完整 manifest 无法进入导入。
- 重复身份不自动合并；旧 staff/superuser 不成为管理员；原哈希兼容有算法和参数上限。
- 素材下载逐跳校验允许来源，阻止内网/业务 API；私有桶未明确时不上传；同包再跑无重复记录/素材。
- 归属为空、跨用户会话、多轮语音复用和缺失素材不获得他人访问权；历史记录不改变当前任务、钱包、订单履约及实时统计。

## 任务 1 加密只读快照

**Files:** `tools/legacy_sync/source.py`、`package.py`、`export.py`、白名单与 Python 测试、依赖清单。

**Interfaces:** 加密 gzip NDJSON 行 `{sourceSystem,sourceTable,sourcePk,values}`；manifest 明确 schema、分片哈希、行数和 `dataSnapshotComplete`，密钥文件独立。

- [ ] 测试禁止 SQL/非法标识、精度与时间、哈希分包隔离、AES 篡改、快照失败和不完整包拒绝，先确认失败。
- [ ] 实现固定白名单和单连接只读游标快照，加密分片、结构前后校验及数量报告；源端无恢复/写入能力。
- [ ] 针对性测试通过后提交，独立只读审查；修复重要问题后只读导出并校验真实包。

## 任务 2 直接上传私有 R2

**Files:** `tools/legacy_sync/assets.py`、素材协议/测试；包内加密资产及引用索引。

**Interfaces:** 引用包含来源行、字段路径、位置和可信归属；对象结果包含新桶/key、SHA-256、大小、MIME、原 ETag 和缺失原因。

- [ ] 测试嵌套 JSON/富文本/相对源址、重复引用与哈希去重、恶意重定向/内网/业务 API、缺失文件、条件上传和 SHA/长度校验，先确认失败。
- [ ] 实现源对象纯读取、流式临时缓存后 R2 上传、校验与断点；临时素材完成即清理，不作为最终本地存储。
- [ ] 私有桶名和配置明确后只读预检，上传到独立迁移前缀；统计成功、缺失、未知来源与版本证据。

## 任务 3 本地兼容数据导入和鉴权素材读取

**Files:** `packages/database/prisma/legacy-sync*`、必要 schema/migration；密码验证器/用户登录更新；媒体 R2 读取与旧日志保护路由、相应测试。

**Interfaces:** 仅消费完成且验证通过的包；dry-run 报告用户身份冲突、原生表映射和归档缺口；apply 仅允许 localhost/127.0.0.1:3604 的 abei。私有 R2 素材只能经管理员或可信用户归属鉴权返回。

- [ ] 真实临时库验证幂等、旧用户状态和身份、密码兼容、四类日志/会话/资产顺序、精度、目标地址守卫、无任务/钱包/管理员副作用，先确认失败。
- [ ] 实现用户及可兼容内容导入；日志只用已完成档案模型。无法兼容的作品、订单和权益保留加密档案并列开发要求。
- [ ] 实现私有 R2 素材保护读取及 Range，验证匿名、普通用户、跨用户及禁用身份不能越权；保持旧本地素材读取兼容。
- [ ] 独立审查后完成隔离演练和第二次导入，确认记录/余额/任务无重复或副作用，再 apply 本地业务库。
