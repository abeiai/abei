# 视频导学制作页自定义预览播放器设计

## 目标

将 `/media-tutor` 制作页中栏的媒体预览从浏览器原生控制条改为与学习页一致的自定义播放控制，减少浏览器差异，并移除播放器下方与左栏重复的媒体状态信息。

## 范围

- 新增制作页专用的媒体预览播放器组件。
- 同时支持视频和音频。
- 保留媒体尚未上传时点击预览区上传的空状态。
- 移除播放器下方的“当前媒体”“上传进度”“字幕预览”区块。
- 字幕编辑继续通过右栏“校对”步骤进入。
- 不修改学习页的阶段播放、逐句导航、互动讲解或跟读逻辑。
- 不修改上传、字幕生成、课件生成、计费和数据库逻辑。

## 播放器交互

制作页播放器使用与学习页一致的底部渐变控制层：

- 进度条位于控制按钮上方。
- 左侧依次为播放或暂停、音量、当前时间与总时长。
- 右侧依次为字幕开关、全屏和更多设置。
- 音量按钮点击后展开音量滑杆。
- 更多设置包含播放速度、循环方式和字幕风格。
- 循环方式支持不循环、当前字幕句循环和整段循环；当前字幕句循环使用制作页已有字幕时间轴。
- 播放过程中鼠标停止移动后自动隐藏控制层；暂停、菜单展开或音量滑杆展开时保持显示。
- 点击视频画面切换播放和暂停。
- 全屏优先使用浏览器 Fullscreen API；不支持或调用失败时使用页面内伪全屏。

## 字幕

- 字幕数据继续使用制作页当前解析出的带时间轴字幕。
- 字幕开关默认在存在字幕时打开。
- 字幕随播放、拖动进度和跳转实时同步。
- 字幕位置随控制层显隐变化：控制层显示时位于控制层上方，隐藏时靠近视频底部。
- 支持白字黑描边、黄字黑描边和灰底白字三种样式。
- 字体规格与学习页共用 `video-guide-player-controls` 中的字幕样式工具。
- 不使用原生 `<track>` 字幕渲染，避免与自定义字幕重复。

## 组件边界

新增 `VideoGuidePreviewPlayer`：

- 输入媒体 URL、媒体类型和带时间轴字幕句子。
- 通过回调上报当前播放时间，由制作页继续负责匹配字幕句子。
- 组件内部管理播放、音量、倍速、循环、全屏、控制层显隐和字幕样式。
- 原生 `<video>` 与 `<audio>` 均不显示 `controls`。

制作页 `VideoGuideConsole`：

- 继续负责上传和字幕时间轴解析。
- 使用 `VideoGuidePreviewPlayer` 替换现有原生媒体元素。
- 删除播放器下方三个重复状态区块。

## 错误与兼容

- 媒体加载失败时保留播放器容器，不影响用户重新上传或从历史课件恢复。
- 使用 `playsInline` 及现有移动浏览器兼容属性。
- 音频使用与视频相同的自定义控制，不再显示浏览器原生音频控制条。
- 控制按钮提供中文 `aria-label`，支持键盘操作。

## 验收

- 视频和音频预览均不出现浏览器原生控制条。
- 自定义播放暂停、拖动、音量、字幕、倍速、循环和全屏可用。
- 字幕能够随播放时间同步，开关和三种样式有效。
- 播放器控制层可以自动隐藏和重新显示。
- 播放器下方不再显示“当前媒体”“上传进度”“字幕预览”。
- 右栏仍可编辑字幕文字。
- `pnpm --filter @xueleai/web typecheck`、测试与生产构建通过。
