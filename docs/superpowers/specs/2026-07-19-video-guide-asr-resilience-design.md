# 视频导学字幕生成鲁棒性设计

## 目标

解决大视频字幕生成在阿里云异步识别阶段超时、服务重启后重复提交、前台缺少阶段反馈的问题，同时保持现有字幕断句和历史数据兼容。

## 设计

1. 视频导学不再把原始视频直接交给语音识别。服务端先通过 ffmpeg 提取为单声道、十六千赫兹、四十八 kbps AAC 音频，上传到 R2 临时目录并校验对象可读取。
2. AI Gateway 为阿里云文件转写提供“提交任务”和“查询任务”两个内部接口。原有同步接口保留，供其他调用方兼容使用。
3. API Core 在课件 JSON 中保存识别任务检查点，包括阿里云 task id、临时音频对象 key、提交时间、最近轮询时间和重试次数。检查点不保存签名 URL 或模型密钥。
4. 后台任务每次运行先读取检查点：已有 task id 时继续查询，不再重复提交；没有 task id 时才提交，并在获得 task id 后立即落库。
5. 轮询采用短请求和分级重试。网络错误、网关错误和限流属于可重试错误；文件不可访问、格式错误、鉴权错误和模型拒绝属于终止错误。默认总等待三十分钟，允许通过环境变量调整，最大六十分钟。
6. 字幕进度沿用现有前端结构，细分为音频准备、上传校验、提交识别、识别处理中、字幕校验、保存完成。用户可以关闭页面，后台继续执行。
7. 成功或明确终止失败后尽力删除临时音频。临时对象统一放在 `video-guide/asr-temp/`，生产 R2 还应配置一天生命周期，处理进程异常退出造成的残留。

## 兼容与安全

- 不新增数据库字段或 migration，检查点存入现有课件 JSON。
- 不修改历史课件；新任务和重新生成任务使用新链路。
- 原始媒体仍使用服务端生成的 R2 签名 URL，不把私有对象公开。
- ffmpeg 只读取系统根据受信 storage key 生成的签名 URL，避免把任意用户 URL 作为转码输入。
- 旧 `/audio/asr` 接口继续可用。

## 验收

- 单元测试覆盖音频提取参数、检查点解析、任务提交/查询成功和失败分类。
- API Core 视频导学测试证明已有 task id 时不会再次提交。
- AI Gateway 测试证明 pending、success、terminal failure 三种状态稳定返回。
- TypeScript 类型检查、API Core 测试和 AI Gateway 测试通过。
