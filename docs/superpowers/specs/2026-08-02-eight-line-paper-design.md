# 八行笺与示范排版设计

## 目标

在 `/zitie` 字帖生成器中新增“八行笺”模板，并为所有模板增加通用的“示范”排版模式。同一份 Layout JSON 继续同时驱动前端 SVG 预览和服务端 SVG 转 PDF，不引入第二套排版逻辑。

## 排版模式

`PracticeLineMode` 新增 `sample`，前端显示名称为“示范”。

示范模式的统一含义：

- 只渲染输入内容的深色示范文字。
- 不渲染描写字。
- 不为抄写预留额外空白行或空白列。
- 难度固定为“描写0个”并禁用。
- 纸张、字体、字号、上下位置、风格、标题、学生信息、页脚、页码和水印继续生效。

现有模板保留原有默认排版，仅在下拉选项中增加“示范”。八行笺默认为“示范”，只提供“示范”和“隔行”，不提供“逐字”和“字母”。

## 八行笺网格

八行笺使用独立的 `eight-line` grid variant：

- 页面主体固定为 8 个等宽竖列。
- 外框使用框格线色，线宽为内分隔线的约 2 倍。
- 7 条内部竖向分隔线使用同一框格线色。
- 不显示横向格线和辅助线。
- 网格左右与学生信息区域对齐，网格高度使用扣除标题、学生信息、页脚和页码后的可用区域。

## 竖排内容

内容顺序是“先列内、后列间”：

1. 从最右侧第一列开始。
2. 同一列内从上到下排列。
3. 当前列写满后，转入左侧下一列。
4. 8 列写满后自动生成下一页。

每列的容量根据可用高度、有效字号和字间距计算。单个字使用不改变字体比例的字号渲染，并使用列边界裁剪作为防溢出保护。

排版坐标按以下公式生成：

```text
column = floor(globalIndex / rowsPerColumn)
row = globalIndex % rowsPerColumn
x = gridRight - columnWidth / 2 - column * columnWidth
y = gridTop + topInset + row * verticalAdvance
```

## 隔行模式

八行笺中的“隔行”按竖排语义解释为隔列：

- 最右侧第一列显示示范文字。
- 其左侧一列留空，供用户书写。
- 后续按“示范列、空白列”从右向左交替。
- 每页最多使用 4 个示范列；写满后自动分页。

## Layout JSON 与渲染

八行笺使用现有绝对坐标 content item，不引入 HTML 或 CSS 排版。

```text
Layout JSON
  -> Web SVG Renderer
  -> API SVG Renderer
  -> svg-to-pdfkit
```

前端和 API 同时识别 `grid.variant = "eight-line"`，输出相同外框、内分隔线、文字坐标、字体和分页。PDF 端不重新排版。

## 测试与验收

- 排版模式中存在“示范”，选中后描写数量为 0 且不可修改。
- 八行笺默认选中“示范”，仅允许“示范”和“隔行”。
- SVG 网格包含 1 个外框和 7 条内竖线，外框线宽大于内线。
- 给定超过单列容量的文字，前一段位于最右列且从上到下，后一段进入左侧下一列。
- 隔行模式仅在第 1、3、5、7 个从右数的列中生成内容。
- 输入超过当页容量时自动分页，所有页可预览并导出到同一 PDF。
- 文字不超出列的左右边界和网格上下边界，不使用 `textLength` 或非等比缩放。
- 前端 SVG 与 API SVG 的网格结构和 content 坐标一致。

## 范围外

- 不增加繁体排版规则或标点旋转。
- 不增加纸张纹理、旧纸背景或印刷噪点。
- 不重构现有模板为通用书写方向引擎。
- 不修改字体管理、扣点、字帖记录或 R2 存储流程。
