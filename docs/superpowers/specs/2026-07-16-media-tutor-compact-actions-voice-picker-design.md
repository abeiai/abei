# 视频导学紧凑操作区与全站音色选择统一设计

## 背景

视频导学制作页右栏当前使用较多说明文字、重复区块和分散按钮，信息密度低，操作层级不够清楚。音色选择在语音体验区、视频导学和英文带学中也存在不同交互，后续维护容易继续分叉。

本次改造聚焦两件事：

1. 将视频导学右栏改为紧凑、状态明确的图标操作区。
2. 抽取全站统一的生成场景音色选择组件。

不修改后端接口、数据库结构、计费规则、异步任务逻辑和学习页面。

## 范围

### 本次覆盖

- `/media-tutor` 视频导学制作页。
- `/experience/voice` 语音体验区。
- 英文带学制作页的讲解音频音色选择。

### 本次不覆盖

- 管理后台音色资产维护、审核和模型配置表单。
- 已生成课件的学习页面播放器交互。
- 语速、音调、音量等各业务独立参数。

## 视频导学右栏

右栏继续使用现有 360px 设置面板和异步状态提示。操作区保留独立步骤边界，但去掉非必要说明文字。

### 媒体素材

- 标题由“媒体”改为“媒体素材”。
- 删除“上传后自动保存”等说明文字。
- 未选择媒体时显示上传图标按钮。
- 已有媒体时显示重新上传图标按钮。
- 按钮使用可聚焦 tooltip：
  - 未上传：上传视频或音频文件。
  - 已上传：重新上传视频或音频文件。
- 保留文件名、大小、保存状态和上传进度。
- 点击重新上传继续复用现有文件选择及草稿覆盖流程。

### 字幕处理

- 标题由“字幕”改为“字幕处理”。
- 删除“上传或识别生成”等说明文字。
- 使用两列两行操作网格：
  - 上传字幕。
  - 生成字幕。
  - 编辑字幕。
  - 下载字幕。
- 每个操作使用图标加短文字，按钮宽度由两列网格稳定约束。
- 上传字幕和生成字幕继续遵循现有媒体就绪条件。
- 编辑字幕只在当前字幕存在时可用。
- 下载字幕只在当前字幕存在时可用。
- 下载时优先使用已保存的服务器字幕地址；若只有当前内存中的字幕文字，则生成 Blob 下载。文件名沿用当前字幕名称，并保持 `.srt` 或 `.ass` 扩展名。
- 保留字幕文件状态、上传进度和识别进度。

### 删除校对区块

删除独立“校对”步骤。编辑字幕入口合并到“字幕处理”的四按钮网格中，继续使用现有字幕编辑弹窗。

### 导学文案

- 删除“基于字幕生成”“文案已就绪”等常驻说明文字。
- 显示两个操作按钮：
  - 没有文案时为“生成文案”，已有文案时为“重新生成”。
  - “编辑文案”只在文案存在时可用。
- 保留现有生成条件、点数确认、异步进度和编辑弹窗。

### 讲解语音

- 删除“先完成文案”“选择音色后合成”等常驻说明文字。
- 使用全站统一的当前音色卡片，点击打开完整音色选择弹窗。
- 视频导学继续只展示支持中文和英文的多语种音色。
- 保留“合成语音”或“重新合成语音”按钮、文案就绪限制、点数确认和异步进度。
- 文案已修改但语音过期时，通过按钮状态和现有任务反馈表达，不新增长说明。

### 随堂练习

- 删除“先完成文案”“可生成”“已生成”等常驻说明文字。
- 按钮文字统一为“生成练习”。
- 已有练习时再次点击仍调用现有重新生成流程。
- 保留文案就绪限制、点数确认和异步进度。

### 底部入口

删除“查看学习页示例”。生成完成后的课件卡片和正式学习页入口保持不变。

## 视频导学中栏

删除“上传完成后从服务器地址加载预览，字幕完成后会同步显示在画面上。”说明文字。

媒体预览仍保持现有行为：

- 上传完成后使用服务器地址加载。
- 字幕完成后在自定义播放器中同步显示。
- 未上传时仍可点击预览区域上传媒体。

## 全站统一音色选择

### 共享组件

从 `voice-console` 抽取受控共享组件，固定放置为：

```text
apps/web/src/components/audio/voice-picker.tsx
```

共享组件包含：

- 当前音色卡片。
- 音色选择弹窗。
- 音色库、我的音色、收藏音色标签页。
- 名称、标签或描述搜索。
- 语种、性别、年龄和标签筛选。
- SSML、Instruct、时间戳能力筛选。
- 试听、收藏和选择操作。
- 空结果、无试听地址和关闭状态。

### 统一数据结构

共享 `VoicePickerOption` 使用稳定的 `value` 作为业务提交值，并支持以下展示字段：

- `name`
- `description`
- `badge`
- `previewAudioUrl`
- `language` / `languages`
- `trait`
- `scene`
- `ageCategory`
- `supportedModels`
- `ssmlSupported`
- `instructSupported`
- `timestampSupported`

各业务负责把接口数据转换成该结构，组件不关心值是系统音色 ID、资产 ID 还是 Provider voice ID。

### 收藏与最近使用

- 使用全站共享的本地存储键保存收藏和最近使用。
- 首次读取时兼容并迁移语音体验区旧键，避免用户已有收藏丢失。
- 三个生成入口共享收藏和最近使用结果。

### 各入口差异

- 语音体验区根据当前模型过滤兼容音色。
- 视频导学只传入支持中文和英文的多语种音色。
- 英文带学传入其可用于讲解音频的音色集合。
- 组件视觉和交互保持一致，业务可用集合和最终提交值仍由各页面控制。

## 可访问性与响应式

- 图标按钮必须有 `aria-label` 和键盘可聚焦 tooltip。
- 禁用按钮保留可识别的禁用样式，不依赖颜色单独表达。
- 音色弹窗支持 Escape 关闭、遮罩关闭和焦点可见样式。
- 桌面端音色列表保持现有完整布局。
- 移动端筛选项自然换行，音色项操作按钮可换行，不产生横向溢出。
- 视频导学右栏的字幕按钮始终保持两列，不因文字长度挤成单字竖排。

## 状态与错误处理

- 所有现有异步状态条、进度条和错误 Toast 继续保留。
- 下载字幕失败时显示“字幕下载失败，请稍后重试”。
- 没有可用音色时显示统一空状态，并禁用语音生成。
- 试听失败不改变当前选择，继续使用现有浏览器音频播放能力。
- 重新上传媒体、重新生成文案和重新生成练习继续覆盖当前课件记录，不创建新记录。

## 测试与验收

### 自动测试

- 音色筛选、收藏和最近使用的纯逻辑测试。
- 视频导学操作可用状态测试：字幕不存在、字幕存在、文案不存在、文案存在。
- 字幕下载优先服务器地址并支持内存 Blob 回退的测试。
- Web TypeScript 类型检查。

### 浏览器验收

- `/media-tutor` 桌面端右栏文字、按钮网格和禁用状态。
- 视频上传、字幕上传或生成后的按钮状态切换。
- 字幕下载文件名和内容。
- 三个前台生成入口打开同一套音色弹窗。
- 收藏和最近使用跨入口同步。
- 390px 移动端无横向溢出，弹窗和按钮文字完整显示。

## 实施规模说明

本次不是单纯文案替换。完整音色弹窗需要从现有页面抽取共享组件，并替换三个入口的选择实现，预计改动超过 150 行。超出部分仅用于共享组件、业务适配、右栏布局和测试，不进行无关重构。
