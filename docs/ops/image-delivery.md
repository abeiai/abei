# 图片交付与 CDN 接入

## 已实现的交付方式

原文件保持原字节与原地址，下载和 AI 参考图仍读取原件。展示图片使用少量固定宽度：64、128、160、320、640、960、1280、1920。不会放大或裁剪；小图 WebP 质量 82，详情和阅读图质量 90。方向先校正，再转换 sRGB 并去除 EXIF；动画与不支持的格式保留原图。压缩失败或结果不值得替换的小原图也保留原件。

- 公开静态/受信任远程图片：`/_next/image?url=...&w=640&q=82`，复用 Next.js 与 Sharp。显式允许的质量为 75（兼容现有 Next Image）、82、90。
- 本地公开媒体文件：`/api/media/files/文件名?w=640`。
- 绘本接口：原图片 URL 增加 `w`；用户、学员、管理员或公开发布状态校验通过后才读取衍生缓存。原接口的 `private, no-store` 不变，不可配置公共 CDN 强制缓存。
- 前端 `ResponsiveImage` 根据用途生成 `srcset/sizes`，浏览器选择实际规格；优化请求失败后回退原地址。`PictureBookImage` 继续提供原有重试和备用源。
- 新增上传与 MediaService 收录的 AI 图片预热 320/640；预热繁忙不影响原图保存。大图及历史图片首次访问按需生成，后续命中缓存，无需迁移数据库或覆盖历史文件。
- 首页、绘本书架、课程卡片及详情、绘本阅读/翻页、创作工作台使用统一交付。未知外部域名保持原图。其他工具中未改造的独立图片组件继续使用原方式。
- 保留已有 Next Image 的音色头像域名兼容，避免全局白名单更新影响原有音色选择器；未连接任何上游容器、数据卷或数据库。

## 缓存与运行

API 缓存默认 `/app/.cache/image-variants`，使用独立 `image_cache` volume，Nginx 不挂载此目录。缓存包含源地址、尺寸、处理版本、`APP_RELEASE_SHA`；每次发布切换版本，避免固定路径示范图命中旧缓存。未提供正式发布版本时，API 每次重启、Web 每次构建使用新缓存版本，便于本地迭代。图片原件仍应保持不可变，替换时使用新文件名。

API 最多并行处理两个冷请求，等待最多 32 个，队列满返回中文 503；已命中缓存的读取不经过处理队列。图片解码限制为 4000 万像素、20MB。缓存定期在生成时清理，目标上限 1GiB、保存 30 天（清理间隔 60 秒，短时间可超出目标）；原图不在此目录。清除该缓存只导致重新生成，不影响业务数据。

Web 使用独立 `web_image_cache` volume，挂载 `/app/apps/web/.next/cache/images`，Next 图片缓存上限 512MiB，最短 TTL 86400 秒，远程响应上限 20MB、禁止跳转。固定路径的静态图源 URL 携带构建发布版本。两个 Compose 项目的卷分别以 `abei_`、`abei-prod_` 隔离。

## 后续接入 CDN

1. `IMAGE_REMOTE_BASE_URLS` 是允许优化的**公开原图源**，多个 HTTPS 地址用逗号分隔，可包含路径前缀。默认 `https://r.abeiai.com`。只填写原图公开地址，不填写 S3 API 端点、密钥或签名地址。
2. `IMAGE_DELIVERY_BASE_URL` 是可选的**图片交付 CDN 域名**，初期留空。启用时 CDN 源站指向本站 Web/API 入口，并放行 `/_next/image` 和 `/api/media/files/`；其他 API 路径不进入这个公开缓存域名。域名只接受 HTTPS origin。
3. 两个参数均为 Web 构建参数，修改后重建 Web 镜像。公开图将请求 CDN 域名；私有和审核状态相关绘本 API 仍保持本站鉴权路径。
4. 缓存键保留 `url/w/q` 与媒体文件 `w`，按照 `Accept` 区分 Next 返回格式，正确保留 `Vary: Accept`。不要忽略这些参数；不要给私有 API 强制设置公共缓存。
5. 受控媒体文件使用新文件名做版本；源站响应的缓存策略由 CDN 尊重。若后续页面需要通过 Canvas 导出跨域图片，应配套配置图片 `crossOrigin` 与 CDN 的 CORS 响应头。
6. 内地节点、备案、源站回源路径和费用由实际 CDN 选型确认。本次仅完成代码准备，没有修改 DNS、开通 CDN、迁移 R2 或发布生产环境。

## 验收记录

测试数据库和 Redis 使用独立临时容器 `abei-image-test-postgres/redis`，端口 3664/3665；不会连接 xueleai 或真实业务数据库。浏览器预览入口 3660，Web/API 为 3661/3662。

执行前后端类型检查与构建、前端完整测试、后端全部绘本及图片相关测试、真实 HTTP 鉴权/原件/尺寸校验。API 上游完整测试包含固定 xueleai 端口和数据库限制，因此未运行与图片无关的全量 API 测试；不为本次优化改写那些测试或连接它们指定的资源。

独立审查发现并修复：compact 标志误降翻页图规格、队列满时原图下载绕过限额、跨部署固定路径缓存陈旧。每项已增加先失败再通过的回归测试。

浏览器验证：首页关键图优先加载；桌面阅读器请求 1920 档，保留原有邻页预加载；390px 手机绘本列表实际选择 320 档。实测示范封面：原图 1024×1024、319158 字节，320 档 44164 字节（减少约 86.2%），640 档 128890 字节（减少约 59.6%）；1920 档保持 1024 原图，未放大。以上为本地样本，不代表全站平均收益。
