# 旧版绘本画面生成提示词补齐

旧版 `Product.result[0].rn_case_pages` 保存页面文字和素材地址，正常页面没有 `prompt` 字段。此前导入器只读取该字段，封面则固定为空，因此没有读取真正保存提示词的位置。

## 来源及匹配

`tools/legacy_sync/book_prompts.py` 将认证的 `abeiai-v1` 作品快照与已导入的历史记录关联。优先级为：

1. 同一作品 `case.extra.draw.data` 中，图片地址及页面文字完全一致的原始 `prompt`。
2. 同一源用户的成功绘图记录。要求来源系统、来源表、确定性原生 ID、`IMAGE` 类型及 `SUCCEEDED` 状态全部一致，原始 `results` 必须包含该页原始图片地址；读取原始输入，其次为旧版中英文提示词。
3. `Product.extra.one_take_id` 明确关联的任务。核对用户、绘本标题、封面图片、页数及各内页图片和正文，使用任务中保存的封面场景和内页 `prompt`。

直接保存在旧页面的有效 `prompt` 仍优先保留。每级来源出现不同候选时保留空白，不用较弱来源猜测；受限字段占位符、非字符串、失败记录、其他用户记录均不能导入。相同文字和页序不足以证明两张不同图片的生成来源。

本次恢复使用既有认证的全量及增量快照和本地已导入日志，没有连接旧 MySQL、发起生成、扣费或上传素材。完整历史 R2 上传保持暂停。

## 增量行为

核心导入和素材回填都调用相同解析器，增量对账也包含 `pages.imagePrompt`。素材回填锁定归属、创建时间、源更新时间及 `version=0` 的绘本，核对全书页位置、正文和语音文稿后，只补空的提示词、图片及音频字段。所有已存在的页字段保留，已完成状态不会因为本批素材缺失而降低。

新增测试通过实际 `import_package` 构造“已恢复提示词后，历史出现歧义”的素材重放，确认恢复过的提示词和音频不会被清空。

## 存量修复及保护

`tools/legacy_sync/book_prompt_repair.py` 提供离线计划和事务 SQL：

1. 对来源身份、归属及创建时间逐本核对，仅计划未编辑且源更新时间一致、全书正文及顺序完全匹配的作品。
2. 目标完整前像及修复计划先写入认证加密档案，独立密钥保存在包外。真实提示词、素材地址、数据库配置和备份不进入 Git 或控制台。
3. 使用原生导入锁及行锁，校验所有非提示词字段的 SHA-256，并逐项验证待补字段为空或已是计划值。任何冲突使整批回滚。
4. 只更新 `picture_books.pages` 内计划位置的 `imagePrompt`。根字段、时间、版本、文字、已有提示词、图片和语音全部保留。
5. 提交后逐本比较全量前后像及保护表摘要，重放同一计划必须零修改，再使用真实运行中的 `PictureBookService.get` 验证编辑器实际读取的页面字段。

绘本公开播放和课程审核快照不包含 `imagePrompt`，无需更新审核快照或摘要。本次无 schema migration、seed 或应用构建、重启、部署。

## 2026-10-10 应用结果

本地及 `new.abeiai.com` 分别补齐 **41,096 本绘本、499,447 页提示词**。原始提示词最长 533 字，全部在现有编辑器 2,000 字限制内，未截断或改写。

认证来源快照共有 42,910 本兼容绘本、508,411 页。其中 1,847 本的 8,964 页无法可靠关联原提示词，保留空白并写入加密 `reports/missing-prompts.enc`，记录具体作品及页面位置。该统计包含旧版未保存提示词、缺少可确认生成记录或候选存在歧义的页面，不代表上传失败。

尾号 0900 的账号，51 本绘本中有 27 本恢复了 267 页提示词；其余 190 页保持空白。《云朵工厂》17 页的作品编辑器原提示词均为空，没有匹配的绘图记录；另查该用户 2,676 份旧工作记录，没有找到额外可补的页面。已有图片和语音保持原状。

两端各 42,944 本绘本的前后像已逐本比较，除计划补齐的位置外完全一致；钱包、流水、预扣、订单、回调日志、管理员、AI 任务、语音任务及资产、媒体资产、课程审核发布及绘本提交共 12 类表的计数和摘要一致。两端同一计划重复执行均为 0 本、0 页修改。

真实运行中的 `PictureBookService.get` 在两端各验证 56 本作品：本地 521 页，线上 528 页（另取的 5 本抽样不同），包含该账号完整 51 本；页面字段与目标备份逐项一致。两端各 3 次跨用户读取均被拒绝。编辑器直接使用该详情中的 `pages.imagePrompt`，刷新创作页即可读取补齐结果。
