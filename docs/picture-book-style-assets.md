# 绘本风格示意图

使用内置 imagegen 逐张生成，未使用 CLI 或项目的付费绘本生成接口。
图片文件位于 `apps/web/public/picture-book-styles/`，均为 640×640 WebP。
运行环境中的示意图通过管理员上传接口存入 R2 的 `abeiai`，风格目录保存对应地址。

## 绘本生成中的使用方式

前台首项为自定义风格，可上传 JPG、PNG 或 WebP 参考图，文件存入 R2。应用内读取和选用均校验上传用户身份，底层对象沿用现有 R2 访问配置。
绘本通过 `custom:<素材ID>` 保存自定义风格，官方风格仍通过稳定 ID 对应后台参考图。
每页生图必带一张风格参考图并放在第一位，后续图片用于角色外观参考；后台描述仅用于展示，不拼入生图提示词。
参考图按实际使用模型的容量截取，优先保留风格图。当前默认 Abei 2.1 最多 10 张参考图，可带 9 张角色图；备用 Qwen Image 3.0 最多 3 张，可带 2 张角色图。

## 公共提示词

儿童绘本创作应用的风格示意图，独立的 1:1 正方形图片。
一个黑色短发、穿红色连衣裙白色领子、戴黄色帽子的小女孩，
和一只白底棕色斑纹的小狗，一起走在森林中的小路上。
女孩与小狗全身完整可见，画面清楚、有亲切感，不要文字、标题、边框、标志或水印。
后续图片使用平面插画原图作为人物与场景的参考，明确要求转换艺术媒介，不添加其他人物或动物。
