# 开发者初始化契约

## 初始化目标

新开发者部署项目后，应能通过后台完成：

```text
创建管理员
设置站点名称
配置 AI Provider
测试模型连接
选择默认模型
启用预置 AI 工具
```

## 初始化检测项

```text
是否存在管理员
是否配置站点名称
是否配置至少一个 AI Provider
是否启用至少一个模型
是否设置默认模型别名
是否配置支付
是否执行过基础 seed
```

## 初始化向导路由

```text
/admin/setup
```

## 环境变量检查页

```text
/admin/system/env-check
```

## 安全要求

1. 不显示完整 API Key。
2. 不显示完整数据库连接串。
3. 不显示支付私钥。
4. 不显示 JWT Secret。
5. 测试连接不扣点。
6. 初始化完成后不再强制跳转。
