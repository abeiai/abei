# 阶段 6：第一阶段整体验收清单

## 目标

确认项目已经达到第一阶段可运营底座标准。

---

## 环境验收

必须满足：

1. 可以通过 `docker compose up -d` 启动 PostgreSQL 和 Redis。
2. 可以运行数据库 migration。
3. 可以运行 seed。
4. seed 创建默认管理员账号。
5. seed 创建默认文章分类。
6. seed 创建至少一篇已发布文章。
7. seed 创建至少一个已发布单页。

---

## 前台验收

必须满足：

1. 可以访问中文首页 `/`。
2. 可以访问文章列表 `/articles`。
3. 可以访问文章详情 `/articles/[slug]`。
4. 可以访问单页详情 `/pages/[slug]`。
5. 前台只展示已发布文章。
6. 前台只展示已发布单页。
7. 草稿文章不可被前台访问。
8. 草稿单页不可被前台访问。
9. 用户可以访问 `/login`。
10. 用户可以访问 `/register`。
11. 用户可以注册。
12. 用户可以登录。
13. 用户可以退出。
14. 用户可以访问 `/dashboard`。

---

## 后台验收

必须满足：

1. 可以访问 `/admin/login`。
2. 管理员可以登录。
3. 管理员可以退出。
4. 未登录管理员访问 `/admin` 会跳转 `/admin/login`。
5. 登录后可以访问 `/admin`。
6. 登录后可以访问 `/admin/categories`。
7. 登录后可以访问 `/admin/articles`。
8. 登录后可以访问 `/admin/pages`。
9. 登录后可以访问 `/admin/settings`。
10. 后台页面主要文字为简体中文。

---

## CMS 验收

必须满足：

1. 管理员可以创建文章分类。
2. 管理员可以编辑文章分类。
3. 管理员可以删除文章分类。
4. 管理员可以创建文章。
5. 管理员可以编辑文章。
6. 管理员可以发布文章。
7. 管理员可以下架文章。
8. 管理员可以删除文章。
9. 管理员可以创建单页。
10. 管理员可以编辑单页。
11. 管理员可以发布单页。
12. 管理员可以下架单页。
13. 管理员可以删除单页。

---

## API 验收

所有 NestJS API 必须使用统一响应格式：

```ts
{
  code: number
  message: string
  data: unknown
}
```

成功响应：

```ts
{
  code: 0,
  message: "成功",
  data: {}
}
```

失败响应：

```ts
{
  code: 40001,
  message: "请求参数错误",
  data: null
}
```

---

## 安全验收

必须满足：

1. 密码哈希存储。
2. JWT Secret 来自环境变量。
3. 数据库连接串来自环境变量。
4. CMS 写操作必须要求管理员登录。
5. 前台用户接口必须验证用户身份。
6. 管理后台接口必须验证管理员身份。
7. 不向用户暴露数据库错误、堆栈信息或原始异常。

---

## 禁止项复查

第一阶段最终代码中不应出现以下能力：

1. Stripe
2. Paddle
3. 多语言路由
4. OAuth 登录
5. 短信登录
6. 魔法链接
7. 复杂权限矩阵
8. 企业多租户
9. RAG
10. 复杂 Agent
11. 可视化页面搭建器

---

## 最终验收命令

```bash
pnpm install
docker compose up -d
pnpm db:migrate
pnpm db:seed
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm dev
```

如果项目暂时没有测试，应至少建立基础测试脚手架，不得永久缺失 `test` script。
