# 分阶段开发行动文档

本目录用于指导 Codex 按阶段开发本项目。

开发总原则：

```text
可见页面 > 登录闭环 > 后台管理 > CMS 内容发布 > 支付充值 > 钱包流水 > AI 能力
```

阶段划分：

1. 阶段 0：仓库初始化与工程骨架
2. 阶段 1：前后台可见页面
3. 阶段 2：用户与管理员认证
4. 阶段 3：CMS 内容管理闭环
5. 阶段 4：支付订单与钱包流水预留
6. 阶段 5：AI 任务与点数消耗预留
7. 阶段 6：整体验收与交付清单

推荐开发方式：

- 每次只让 Codex 执行一个阶段中的一个小任务。
- 每个任务必须明确允许修改的目录。
- 每个任务完成后必须运行验收命令。
- 所有页面与错误提示必须使用简体中文。
