# 阶段 17：开发者初始化向导

## 目标

让新开发者首次部署项目时，可以通过后台向导完成站点、管理员、AI Provider、默认模型和预置工具配置。

本阶段重点提升开箱即用体验。

---

## 允许修改目录

```text
apps/web/
apps/api-core/
packages/database/
docs/
scripts/
```

---

## 本阶段任务

```text
116 首次启动检测
117 后台初始化向导
118 环境变量检查页
119 README 升级
```

---

## 任务 116：首次启动检测

### 目标

系统首次启动时判断是否完成关键初始化。

### 检测项

```text
是否存在管理员
是否配置站点名称
是否配置至少一个 AI Provider
是否启用至少一个模型
是否设置默认模型别名
是否配置支付
是否执行过基础 seed
```

### 行为

如果未初始化，访问后台时引导到：

```text
/admin/setup
```

### 要求

1. 初始化状态必须存储在数据库或可计算得出。
2. 不得阻止 health check。
3. 不得影响命令行 seed。
4. 初始化完成后不再强制跳转。

---

## 任务 117：后台初始化向导

### 路由

```text
/admin/setup
```

### 推荐步骤

```text
1. 创建管理员
2. 设置站点名称
3. 选择 AI Provider
4. 填写 API Key
5. 测试模型连接
6. 选择默认模型
7. 选择是否启用预置 AI 工具
8. 完成
```

### 要求

1. 每一步都有中文说明。
2. 可以跳过 AI 配置，但要提示后果。
3. API Key 不显示明文。
4. 测试连接不扣点。
5. 向导完成后写入系统设置。

---

## 任务 118：环境变量检查页

### 路由

```text
/admin/system/env-check
```

### 检查项

```text
数据库连接
Redis 连接
JWT Secret
支付配置状态
AI Provider 配置状态
对象存储配置状态
邮件服务配置状态
APP_BASE_URL
API_BASE_URL
```

### 展示规则

```text
已配置
未配置
连接正常
连接失败
```

### 禁止

```text
1. 不显示密钥原文。
2. 不显示完整数据库连接串。
3. 不显示完整 API Key。
```

---

## 任务 119：README 升级

### 目标

把 README 升级为开发者友好的快速启动文档。

### 必须包含

```text
1. 项目介绍
2. 适合场景
3. 5 分钟本地启动
4. 环境变量说明
5. 如何配置 AI Provider
6. 如何配置支付宝 / 微信支付
7. 如何发布第一篇文章
8. 如何创建第一个 AI 工具
9. 如何部署到服务器
10. 常见问题
```

### 要求

1. 以简体中文为主。
2. 命令可复制执行。
3. 不包含真实密钥。
4. 与当前项目脚本保持一致。

---

## 本阶段禁止事项

```text
1. 不做多语言向导。
2. 不做复杂安装器。
3. 不在 README 中放真实密钥。
4. 不在向导中绕过已有权限体系。
```

---

## 验收标准

```text
1. 首次访问后台会进入初始化向导。
2. 可以通过向导创建管理员。
3. 可以设置站点名称。
4. 可以选择并测试 AI Provider。
5. 可以选择默认模型别名。
6. 可以启用预置 AI 工具。
7. 环境变量检查页不泄露密钥。
8. README 可以指导新开发者完成本地启动。
```
