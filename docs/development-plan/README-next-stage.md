# 后续阶段开发行动文档

本目录用于指导 Codex 在 MVP 底座完成后，继续推进上线、支付、AI、运营和增长能力。

## 前置条件

默认以下内容已经完成：

1. 前台可见页面已完成。
2. 后台管理后台已完成。
3. 用户注册登录已完成。
4. 管理员登录已完成。
5. CMS 已完成。
6. Mock 支付和钱包闭环已完成。
7. Mock AI 任务和点数消耗闭环已完成。

## 后续开发总原则

```text
上线硬化 → 生产部署 → 真实支付 → 真实 AI → 运营后台 → 内容增长 → 前台产品化 → 高级 AI
```

## 后续阶段

1. 阶段 7：上线前硬化
2. 阶段 8：生产部署能力
3. 阶段 9：真实支付宝 / 微信支付接入
4. 阶段 10：真实 AI Provider 接入
5. 阶段 11：后台运营能力增强
6. 阶段 12：CMS 增强与内容增长
7. 阶段 13：产品化前台增强
8. 阶段 14：高级 AI 能力

## Codex 开发纪律

- 每次只执行一个小任务。
- 每个任务必须明确允许修改目录。
- 所有页面、按钮、错误提示必须使用简体中文。
- 不得引入本阶段以外的复杂能力。
- 完成后必须运行可用的 lint、typecheck、test、build。
- 涉及数据库的任务必须包含 migration 和 seed 更新说明。
