# 阶段 22：前台语音工具体验

## 目标

在前台开放语音合成、声音设计、声音复刻和用户音色库，让普通用户可以实际使用语音能力。

本阶段必须依赖阶段 21 的 `AudioTask`、`VoiceAsset`、对象存储和后端接口。

## 允许修改目录

```text
apps/web/
apps/api-core/
apps/ai-gateway/
packages/database/
docs/
```

## 本阶段任务

```text
136 前台语音合成工具页
137 前台声音设计工具页
138 前台声音复刻工具页
139 我的音色库

```

## 任务 136：前台语音合成工具页

### 路由

```text
/tools/text-to-speech
```

### 功能

```text
输入文本
选择音色
选择模型
设置语速
设置语调
设置音量
选择输出格式
生成音频
在线试听
下载音频
查看预计消耗点数
查看实际消耗点数
```

### 表单字段建议

```text
text
voiceAssetId
modelAlias
speed
pitch
volume
format
sampleRate
```

### 要求

1. 未登录用户提交时提示登录。
2. 点数不足时提示充值。
3. 模型未配置时提示后台配置。
4. 生成前显示预计点数。
5. 生成后显示实际扣点。
6. 支持在线播放和下载。
7. 文本长度必须有限制。
8. 所有提示使用简体中文。

## 任务 137：前台声音设计工具页

### 路由

```text
/tools/voice-design
```

### 功能

```text
输入声音描述
输入试听文本
选择 target_model
生成音色
试听预览
保存音色
使用该音色进行语音合成
```

### 文案示例

```text
请描述你想要的声音，例如：温暖的年轻女性声音，语速自然，适合儿童绘本朗读。
```

### 要求

1. 设计成功后创建 `VoiceAsset`。
2. 保存 `providerVoiceId`。
3. 保存 `targetModel`。
4. 保存 `previewAudioUrl`。
5. 失败时释放冻结点数。
6. 用户只能管理自己的设计音色。

## 任务 138：前台声音复刻工具页

### 路由

```text
/tools/voice-clone
```

### 功能

```text
上传 10–20 秒音频样本
显示录音质量要求
填写音色名称
选择 target_model
勾选授权声明
提交复刻任务
轮询任务状态
复刻完成后试听
使用该音色进行语音合成
```

### 页面必须提示

```text
请上传本人声音或已获得授权的声音样本。
请勿上传他人声音、公众人物声音或用于冒充他人的音频。
建议上传 10–20 秒清晰、无背景噪音、无长静音的音频。
```

### 要求

1. 没有勾选授权声明不得提交。
2. 必须创建 `VoiceConsent`。
3. 上传音频必须限制格式和大小。
4. 样本音频必须进入对象存储。
5. 复刻音色默认 `PRIVATE`。
6. 如果系统开启审核，复刻完成后进入待审核状态。
7. 失败时释放冻结点数。

## 任务 139：我的音色库

### 路由

```text
/dashboard/voices
```

### 功能

```text
系统音色
我的复刻音色
我的设计音色
音色状态
试听
重命名
删除
设为默认音色
```

### 音色类型

```text
SYSTEM
CLONED
DESIGNED
```

### 音色状态

```text
CREATING
READY
FAILED
PENDING_REVIEW
DISABLED
DELETED
```

### 要求

1. 用户只能查看自己的私有音色。
2. 系统音色所有用户可见。
3. 被禁用音色不可用于合成。
4. 删除音色不应破坏历史任务记录。
5. 删除前显示确认提示。
