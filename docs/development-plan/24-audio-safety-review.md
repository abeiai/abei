# 阶段 24：语音安全、授权与审核

## 目标

为声音复刻 / 语音克隆能力建立授权、风险提示、审核和违规处理机制。

本阶段是语音能力必须项，不得后置到正式上线之后。

## 允许修改目录

```text
apps/web/
apps/api-core/
packages/database/
docs/
```

## 本阶段任务

```text
144 声音复刻授权记录
145 敏感用途提示与使用协议
146 管理员审核开关
147 违规音色处理
```

## 任务 144：声音复刻授权记录

### 推荐模型

```text
VoiceConsent
- id
- userId
- voiceAssetId
- consentText
- consentType
- ownerName
- ownerContact
- agreedAt
- ip
- userAgent
- createdAt
```

### consentType

```text
SELF_VOICE
AUTHORIZED_VOICE
```

### 授权声明示例

```text
我确认上传的音频为本人声音，或我已获得声音权利人的明确授权。我承诺不会将该音色用于冒充他人、诈骗、侵权、虚假宣传或其他违法违规用途。
```

### 要求

1. 没有授权记录，不允许创建声音复刻任务。
2. 授权记录必须保存 IP 和 User-Agent。
3. 授权声明文本必须保存快照。
4. 用户可以在任务详情中查看自己的授权记录。
5. 管理员可以在后台查看授权记录。

## 任务 145：敏感用途提示与使用协议

### 需要增加的位置

```text
/tools/voice-clone
/tools/voice-design
/dashboard/voices
下载生成音频时
```

### 必须提示

```text
AI 生成语音可能被误用，请勿用于冒充他人、诈骗、侵权、虚假宣传或违法违规用途。
声音复刻仅允许上传本人声音或已获得授权的声音。
生成音频建议标注为 AI 生成语音。
```

### 要求

1. 语音复刻页面必须强制勾选协议。
2. 语音设计页面显示风险提示。
3. 下载音频前可显示轻量提示。
4. 协议文案可在后台配置。

## 任务 146：管理员审核开关

### 系统设置

```text
声音复刻是否需要管理员审核
声音设计是否需要管理员审核
用户是否可公开音色
复刻音色默认可见性
设计音色默认可见性
```

### 推荐默认值

```text
声音复刻默认需要审核
声音设计默认不需要审核
用户音色默认私有
不允许用户公开音色
```

### 要求

1. 开启审核时，音色创建成功后进入 `PENDING_REVIEW`。
2. 审核通过后状态变为 `READY`。
3. 审核拒绝后状态变为 `DISABLED` 或 `REJECTED`。
4. 未通过审核的音色不可用于合成。
5. 审核操作必须记录管理员操作日志。

## 任务 147：违规音色处理

### 后台能力

```text
禁用音色
删除音色
查看来源样本
查看授权记录
查看生成记录
查看使用该音色的任务
```

### 要求

1. 禁用后不可用于新合成任务。
2. 历史任务记录保留。
3. 删除操作需要二次确认。
4. 操作必须记录管理员操作日志。
5. 用户前台显示中文原因。

## 本阶段禁止事项

```text
不允许无授权复刻
不允许默认公开用户复刻音色
不允许绕过审核使用待审核音色
不做公开音色交易市场
不自动判断用户是否真实获得授权，第一版只做声明和审计
```

## 验收标准

```text
声音复刻必须勾选授权声明
授权记录保存成功
后台可以查看授权记录
系统设置可以控制是否审核
待审核音色不可用于合成
管理员可以审核音色
管理员可以禁用违规音色
所有敏感提示为简体中文
```
