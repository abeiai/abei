# 阶段 11：后台运营能力增强

## 目标

将管理后台从 CMS 后台升级为可运营 SaaS 后台。

本阶段重点是用户、钱包、订单、AI 任务、系统设置和操作日志。

## 允许修改目录

```text
apps/web/
apps/api-core/
packages/database/
docs/
```


## 任务 071：用户禁用 / 启用

### 要求

```text
1. 禁用用户后不能登录。
2. 已登录用户下次请求应被拒绝。
3. 操作必须记录管理员操作日志。
4. 错误提示为简体中文。
```


## 任务 073：管理员手动加减点数

### 要求

```text
1. 只能管理员操作。
2. 必须填写原因。
3. 必须写入 ADMIN_ADJUST 流水。
4. 必须记录管理员操作日志。
5. 不允许扣成负数。
```

## 任务 079：系统设置页面真实可用

### 路由

```text
/admin/settings
```

### 设置项

```text
站点名称
站点 Logo
首页标题
首页描述
SEO 标题
SEO 描述
备案号
客服二维码
默认点数兑换比例
默认 AI 模型
```

### 要求

```text
1. 设置项保存到数据库。
2. 前台首页可以读取部分设置。
3. 敏感设置不得直接暴露给前台。
```

## 本阶段禁止事项

```text
1. 不做复杂多角色权限矩阵。
2. 不做企业多租户。
3. 不做订阅自动续费。
4. 不做 RAG / Agent。
5. 不做多语言后台。
```

## 验收标准

```text
1. 管理员可以查看用户列表。
2. 管理员可以查看用户详情。
3. 管理员可以禁用和启用用户。
4. 管理员可以查看用户钱包和流水。
5. 管理员可以手动加减点数且有日志。
6. 管理员可以查看订单列表和详情。
7. 管理员可以查看 AI 任务列表和详情。
8. 管理员可以查看操作日志。
9. 系统设置可以保存并生效。
```
