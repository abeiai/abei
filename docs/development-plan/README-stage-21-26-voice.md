# 阶段 21–26：语音能力后续开发行动文档

本目录用于指导 Codex 在现有中文 AI SaaS / 工具站底座基础上，继续集成语音合成、声音设计、声音复刻 / 语音克隆能力。

## 前置条件

1. MVP、支付、钱包、AI Provider、工具模板、后台运营、用量统计、Starter Kit 产品化能力已完成。
2. 系统已经具备对象存储或对象存储预留。
3. 系统已有用户中心、后台管理、任务系统、钱包预冻结与结算机制。

## 总目标

将项目从“文本 AI SaaS / 工具站底座”升级为“多模态中文 AI SaaS 底座”，新增：

```text
语音合成
声音设计
声音复刻 / 语音克隆
用户音色库
语音任务管理
语音计费扣费
声音复刻授权与审核
后台语音运营管理
语音工具模板和 Demo 数据
```

## 总体开发纪律

1. 前端不得直接调用阿里云。
2. FastAPI 只负责调用阿里云语音接口，不负责扣点、权限、钱包和审计。
3. NestJS 负责用户、权限、任务状态、计费、扣点、审计和安全策略。
4. 所有语音任务必须走 `AudioTask`。
5. 所有计费任务必须走钱包预冻结、成功结算、失败释放。
6. 声音复刻必须先记录授权声明。
7. 用户上传声音样本不得长期公开访问。
8. 不得把 `DASHSCOPE_API_KEY` 写入代码、seed、日志或文档示例。
9. 所有界面、按钮、提示和错误信息必须使用简体中文。
10. 语音复刻能力默认遵循“用户音色私有、管理员可审核、违规可禁用”原则。
