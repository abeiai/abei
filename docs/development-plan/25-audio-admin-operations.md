# 阶段 25：后台语音运营管理

## 目标

在管理后台新增完整的语音运营能力，让管理员可以管理语音模型、用户音色、语音任务、语音计费和语音审核。

## 允许修改目录

```text
apps/web/
apps/api-core/
packages/database/
docs/
```

## 本阶段任务

```text
148 语音模型管理
149 用户音色管理
150 语音任务管理
151 语音计费配置
152 语音审核列表
```

## 后台菜单建议

```text
语音能力
  - 语音模型
  - 系统音色
  - 用户音色
  - 语音任务
  - 语音计费
  - 语音审核
  - 语音用量
```

## 任务 148：语音模型管理

### 路由

```text
/admin/audio/models
```

### 管理字段

```text
模型名称
Provider
地域
能力标签
是否启用
价格倍率
默认用途
是否支持语音合成
是否支持声音设计
是否支持声音复刻
```

### 要求

1. 管理员可以启用 / 禁用模型。
2. 管理员可以设置模型用途别名。
3. 禁用模型后不可被新任务使用。
4. 修改必须记录管理员操作日志。

## 任务 149：用户音色管理

### 路由

```text
/admin/audio/voices
/admin/audio/voices/[id]
```

### 列表字段

```text
音色名称
用户
类型
Provider voice_id
target_model
状态
可见性
审核状态
创建时间
```

### 详情页展示

```text
音色基础信息
预览音频
来源样本
授权记录
使用记录
任务记录
管理员操作日志
```

### 要求

1. 管理员可以禁用音色。
2. 管理员可以删除音色。
3. 管理员可以查看授权记录。
4. 管理员可以查看来源样本的临时访问链接。
5. 不显示永久公开样本 URL。

## 任务 150：语音任务管理

### 路由

```text
/admin/audio/tasks
/admin/audio/tasks/[id]
```

### 列表字段

```text
任务类型
用户
模型
音色
状态
字符数
消耗点数
错误信息
创建时间
完成时间
```

### 详情展示

```text
任务状态
输入文本摘要
输出音频
Provider 请求 ID
错误信息
钱包流水
用量日志
审计记录
```

### 要求

1. 支持按用户、状态、任务类型筛选。
2. 支持查看失败原因。
3. 支持查看关联钱包流水。
4. 不允许管理员随意修改成功任务输出。

## 任务 151：语音计费配置

### 路由

```text
/admin/audio/pricing
```

### 可配置项

```text
语音合成每千字符点数
声音设计每次点数
声音复刻每次点数
最低扣费
模型倍率
失败是否退点
试听是否免费
```

### 要求

1. 修改计费规则必须记录管理员操作日志。
2. 禁用规则后相关任务不可执行。
3. 显示最近更新时间。
4. 前台提交任务时使用最新规则。

## 任务 152：语音审核列表

### 路由

```text
/admin/audio/reviews
```

### 审核内容

```text
待审核音色
授权声明
样本音频
预览音频
用户信息
任务信息
审核通过
审核拒绝
禁用音色
```

### 要求

1. 审核通过后音色可用。
2. 审核拒绝后音色不可用。
3. 审核操作必须填写原因。
4. 审核操作必须记录管理员操作日志。
5. 用户前台可看到审核结果。

## 本阶段禁止事项

```text
不做公开音色交易市场
不做自动内容审核模型
不允许绕过授权和审核流程
不暴露用户样本音频永久公开 URL
不允许管理员直接修改 Provider voice_id
```
