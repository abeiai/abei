# 阶段 15–20 后续开发行动文档

本目录用于指导 Codex 在完成 MVP、上线硬化、真实支付、真实 AI、运营后台、CMS 增强之后，继续把项目打磨成一个真正可复用、可快速部署、可快速接入 AI 能力的中文 AI SaaS / 工具站底座。

## 当前默认前置条件

1. 前台、后台、用户系统、管理员系统已完成。
2. CMS、支付、钱包、AI 任务闭环已完成。
3. 真实支付宝 / 微信支付已完成或至少已具备接入框架。
4. 真实 AI Provider 接入已完成或至少已有 OpenAI-compatible Provider 能力。
5. 后台具备基础运营能力。
6. 项目已经具备生产部署能力。

## 后续开发总目标

让新开发者 clone 项目后，只需要：

```text
1. 安装依赖
2. 配置数据库和 Redis
3. 填写自己的 AI Provider API Key
4. 点击后台测试连接
5. 启用默认模型和预置工具
```

即可快速拥有一个可运营的 AI SaaS / AI 工具站底座。

## 阶段划分

```text
阶段 15：AI 模型预置与快速接入体系
阶段 16：AI 工具模板与场景市场
阶段 17：开发者初始化向导
阶段 18：模型调用监控与成本统计
阶段 19：插件化与扩展能力
阶段 20：Starter Kit 产品化交付
```

## 开发纪律

1. 每次只执行一个小任务。
2. 不得把真实 API Key 写入代码、seed、日志或文档示例。
3. 不得把具体模型名硬编码到业务逻辑中。
4. 业务场景必须通过 `modelAlias` 访问模型。
5. Provider、Model、Tool、Scenario 必须配置化。
6. 所有后台界面、错误提示、按钮文案必须使用简体中文。
7. 所有涉及数据库变更的任务必须提供 migration 和 seed 更新说明。
8. 每个阶段完成后必须运行 lint、typecheck、test、build。
