# 公众号扫码登录实现与验收

日期：2026-10-07。方案见 [替换方案](wechat-mp-scan-login-replacement-plan.md)，配置见 [README](../README.md)。

## 已实现

- 移除网站微信 OAuth authorize/callback、WEB 配置、旧 state/Cookie；微信支付的独立授权流程保留。
- 公众号临时 QR_STR_SCENE；安全模式消息验签、AES 解密、AppID/接收账号校验；subscribe、SCAN、确认文字及取消关注处理。
- HttpOnly 浏览器上下文、Origin/CSRF、180 秒挑战、随机六位确认码、Redis 原子状态、消息去重、领取一次、登录互斥与限流。
- 同公众号旧 OpenID 命中原用户，UnionID 可空；禁用及身份冲突失败关闭，不覆盖原资料/钱包。
- 未匹配身份只进入待处理状态。已有邮箱/密码或标准短信验证后绑定；创建必须明确选择、通过短信且注册开关开启。密码或手机号在校验后改变时拒绝绑定。
- 简体中文二维码面板、手机返回恢复查询、过期/刷新/关闭；已有账号绑定、新账号创建及邮箱入口。
- 默认关闭公众号登录及新用户注册。不增加数据库 migration 或真实数据 seed。
